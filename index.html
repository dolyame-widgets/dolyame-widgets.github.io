Виджеты Долями для сайта магазина

Зачем магазину виджеты?

Виджет - небольшой готовый блок на сайте. Он показывает покупателю, что товар можно оплатить частями, прямо в интерфейсе магазина.

  • 1

    Влияют на решение о покупке

    Покупатель видит доступный способ оплаты в момент выбора товара.

  • 2

    Помогают увеличить средний чек

    Средний чек растёт до 81% - по опыту наших партнёров.

  • 3

    Покупатели возвращаются

    Покупателям нравится платить Долями: они приходят за новыми покупками и могут позволить себе больше, чем при оплате картой сразу.

Инструкция для самостоятельной установки

Виджеты подключаются через сниппет. Сниппет - небольшой фрагмент готового кода, который добавляется на сайт для подключения виджета.

  1. Получите site ID

    Это число - уникальный идентификатор вашего сайта. Его предоставляет сотрудник сервиса Долями. Если site ID у вас ещё нет, напишите на widget_dolyame@tbank.ru.

  2. Добавьте сниппет на сайт

    Установите скрипт на каждую страницу сайта в секцию <head>. Вместо siteID укажите ваш site ID.

    <script type="text/javascript">
  var digiScript = document.createElement('script');
  digiScript.src = '//aq.dolyame.ru/siteID/client.js';
  digiScript.defer = true;
  digiScript.async = true;
  document.head.appendChild(digiScript);
</script>

  3. Дождитесь запуска

    Сразу после установки на сайте ничего не изменится. Виджеты не появляются автоматически: сотрудники Долями сообщат, когда согласованные блоки готовы к запуску.

Технические детали из официальной инструкции

Параметр site ID представляет собой число - уникальный идентификатор вашего сайта, который предоставляется сотрудником сервиса Долями.

Скрипт доступен по протоколам HTTP и HTTPS - необходимо использовать тот же протокол, который использует сам сайт.

Расположение скрипта в начале секции body минимизирует время отрисовки промо-элементов Долями. Оптимальной будет приоритетная позиция скрипта в общем коде после элементов страницы и GTM.

Наличие в скрипте атрибутов defer и async исключает влияние запускаемых промо-элементов на загрузку страницы.

Установка сниппета - предварительный шаг для возможности верстки и запуска промо-элементов. Сразу после установки сниппета на сайте не произойдет никаких изменений.

Промо-элементы не появляются автоматически - сотрудники сервиса Долями проинформируют вас о готовности к запуску согласованных блоков.
